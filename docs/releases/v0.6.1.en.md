# NAVI v0.6.1 — Animation playback hotfix (Preview)

Fix playback and selection of the existing 110 animations in the embedded companion and Windows overlay.

## Fixed

- Ambient expressions and their return-to-idle messages no longer cancel a selected animation or the full catalogue preview. Selection remains available during short ambient reactions; real active model requests still take priority.
- Windows previews loop locally instead of holding their final pose while waiting for another Webview packet.
- Explicit greeting previews work after listening/thinking. Automatic greetings still yield to active interactions and previews.
- Stopping a preview restores the latest companion expression. Returning to a visible Webview resends its active preview to the overlay.
- Natural idle clips use their catalogue duration, avoiding long holds after choreography has ended. The embedded view rests after 90 quiet seconds instead of nine.
- Reset progress immediately on clip changes.

## Validation

- All 110 selections exercised in actual Chromium DOM/CSS over multiple controlled-clock cycles, including ambient-expression updates. The complete 110-item sequence, pause/resume, request preemption and expression restoration pass.
- All 110 previews rendered through the actual Windows GDI+ renderer over two complete cycles, with visibility and changing-raster assertions. Native playback tests cover looping and greeting transitions.
- 83 JavaScript/TypeScript tests pass. Native Go tests, the existing real-browser regression suite and isolated VS Code Host checks cover the surrounding behavior. The host test checks controller-to-transport preview ownership separately from physical overlay arrival.
- The new catalogue browser audit runs in GitHub CI and publishes its JSON report as an artifact.

## Known limitation

Measured diagnostic flight remains experimental and separate from this animation fix. Its hosted Windows window-test beacon detection failed in v0.6.0; complete VS Code-to-overlay anchor acceptance remains open. This hotfix does not claim to resolve it. Human visual acceptance in your normal VS Code profile remains separate from automated rendering checks.

Install `navi-copilot-companion-0.6.1.vsix` using **Extensions → … → Install from VSIX…**, then reload VS Code. Open **NAVI: Open Companion**, expand **110 Bewegungen entdecken**, select a motion or use **Alle ansehen**. The 110 catalogue entries include contextual greetings/listening/rest; 94 suitable entries rotate naturally during idle.
