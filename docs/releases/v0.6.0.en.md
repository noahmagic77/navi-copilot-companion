# NAVI v0.6.0 — Active programming companion (Preview)

NAVI makes space while you edit, offers bounded help, navigates diagnostics and applies an existing preferred Quick Fix after your explicit action. Confirmed memories and a live brain inspector make companion state visible.

**Preview limitation:** measured diagnostic flight is experimental on Windows x64. Native live landing and three actual VS Code renderer cases pass separately. Complete VS Code-to-overlay flight acceptance remains open because the isolated test could not activate/bind its owner window. Missing or ambiguous detections retain the editor marker instead of guessing a target.

## Coding assistance

- Right-click NAVI in either view to cycle diagnostics, select known workspace problems, open Quick Fixes or prepare selected code for discussion with `@navi`.
- **Fix Problem** revalidates the document, diagnosis and selection. A single preferred Quick Fix applies after your click; multiple or non-preferred actions remain a choice. No available correction means no edit. VS Code provides undo; NAVI does not save automatically or add a model call.
- Explicit navigation highlights the problem and adds a fairy gutter marker. The Windows overlay can track a unique two-colour editor beacon and fly to its measured height, 60 DIPs to the left. Opt out with `navi.overlay.editorAnchors`.
- Detection reads only the active owner window's client pixels, at most four times per second for 20 seconds. Frames are immediately discarded from RAM: no OCR, saved images or transmission. Edits, focus loss, games and manual controls cancel tracking; mouse avoidance takes precedence.

## Companion, memory and expression

- Make space after three editor changes in five seconds; return after ten quiet seconds. Diagnostic offers require editor quiet and are limited to one per five minutes and three per hour. Files open only on an explicit action; initiative can be disabled.
- Shared body, wing and light profiles react to editor, save, diagnostic, task, debug, focus and contact events. Simulated attention, settling, breathing and pointer gaze add variety without further model requests. `navi.companion.lifelike` controls this layer.
- Keep the 110-motion catalogue, vary natural idle movement, add three mouse games and click-triggered sparkle/escape reactions. Transparent speech tails follow the rendered luminous core; repeated NAVI labels are removed.
- Opt-in memories store only explicitly confirmed preferences, project notes, tasks and next steps. Profile and workspace entries stay separate and can be edited, deleted or reset.
- **NAVI: Live Brain** shows actual perception, state, decisions, reasons, expressions and capabilities. Refresh only while visible, at most four times per second. The last 50 decisions stay in RAM without code or message text. The concept graphic remains a simulation.
- Voice has an existing-provider adapter and explicit start/stop lifecycle. No compatible real recording/transcription provider is connected here, so listening remains unavailable with an explanation. No new model or cloud service is required.

## Removed analysis and data handling

Prompt scoring, the checker UI/command, topic-change analysis, OTel imports, the session journal, SQLite indexing and analytics commands are removed. Old user files remain untouched and are no longer loaded. Own-chat history and confirmed memories remain separate opt-ins, both off by default. Bounded editor context stays in RAM and is not sent to a model automatically.

## Validation and remaining acceptance

- 83 JavaScript/TypeScript tests and native Go tests pass, covering decisions, budgets, stale diagnoses, memories, voice lifecycle, motion, protocol and anchor safety.
- Actual isolated VS Code checks cover diagnostic cycling, preferred fixes, undo, ambiguous/missing corrections and edits during resolution. Earlier focused runs cover make-space/return timing, save and task reactions; focus-dependent timings were explicitly skipped in the final host run.
- Browser checks cover motion, attached speech, actions and live-brain rendering. Native window checks cover measured landing, owner movement, hiding/minimizing, speech click-through, right-click actions and clean shutdown.
- Full diagnostic flight in normal VS Code, combined game interactions, real model/debugger/microphone flows and human visual acceptance remain open. Native overlay requires Windows x64; the embedded companion remains available elsewhere.
