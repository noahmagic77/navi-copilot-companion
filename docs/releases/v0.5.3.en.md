# NAVI v0.5.3 — Open-source companion foundation

[Deutsch](https://github.com/noahmagic77/navi-copilot-companion/blob/v0.5.3/docs/releases/v0.5.3.de.md) · [Roadmap (German)](https://github.com/noahmagic77/navi-copilot-companion/blob/v0.5.3/docs/roadmap.md) · [Project status (German)](https://github.com/noahmagic77/navi-copilot-companion/blob/v0.5.3/docs/STATUS.md)

This experimental preview adds the first local brain-state foundation, connects existing AI activity to the fairy, and improves speech bubbles and animation visibility. It does not introduce another model or require a new model server.

## Changes

- **Open source:** replace the previous restrictive license with MIT. Add contribution guidance and third-party notices, including the Go runtime license. Third-party products and models retain their own terms.
- **Brain foundation A1:** add a deterministic state reducer and bounded self-model observing selected activity and window focus. Distinguish implemented capabilities, past successful observations and unknown availability. Keep this state in RAM without storing prompts or answers.
- **State explanation:** add **NAVI: About My State / Eigenen Zustand erklären**, which opens a rule-based snapshot of NAVI's state, source, reason, capabilities and limits without another model call.
- **Existing VS Code model:** show busy, completed, cancelled and error states for NAVI's own selected-model requests while preserving streaming, cancellation and opt-in history.
- **Codex handoff:** bundle a dependency-free stdio MCP adapter with authenticated per-window local IPC. Add `navi_show_message`, `navi_set_status`, a configuration command and manual text sharing. Concurrent activities cannot freely overwrite the current request.
- **Speech bubbles:** replace native system tooltips with a rounded translucent surface, readable text and a tail tracking the fairy core. The companion bubble also becomes translucent, follows the core and hides its tail with the message.
- **Animation:** strengthen normal and preview trajectories, gestures and light pulses. Refine idle scheduling to wait for quiet periods and avoid interrupting active prompts or important bubbles. Preserve the shared 110-motion catalogue, pause and visibility controls.
- **Documentation:** add the mathematical brain concept, technical specification, implementation plan, status report and an interactive offline brain diagram with six simulated scenarios. The diagram is not a live view of the extension.

## Install and try

Download `navi-copilot-companion-0.5.3.vsix` and its SHA-256 file from this release. In VS Code Desktop, select **Extensions → … → Install from VSIX…**, install the file and reload the window.

1. Send a request to `@navi` using an available model in VS Code Chat.
2. Run **NAVI: About My State / Eigenen Zustand erklären** to inspect a state snapshot.
3. For Codex, run **NAVI: Configure Codex Connection / Codex-Verbindung einrichten**. Add the generated block to the actual Codex client's MCP configuration and restart that client. Regenerate the per-window connection after reloading NAVI.
4. Ask the connected client to use `navi_show_message` for an explicit message handoff. The VS Code window must be focused and speech bubbles enabled to see the result.

The MCP bridge was tested with the installed VS Code runtime, so no separate Node installation was required in that Windows test. The existing model access and supported Codex host configuration remain prerequisites. NAVI does not read unrelated chats or private reasoning.

## Validation and limits

48 JavaScript/TypeScript tests, Go tests and the browser runtime checks passed locally. Tests cover deterministic replay, capability reporting, concurrency, cancellation, authenticated IPC, real MCP stdio traffic, native bubble raster properties and visible browser activity. The packaged MCP adapter was also tested with the installed VS Code runtime. Fairy audio was confirmed audible by the project owner.

Full live validation of the latest visual changes, the state-explanation command, real model turns and the actual Codex client connection remains pending. The brain foundation is not a general autonomous planner, persistent companion memory or diagnosis navigation. A completed model response does not prove correct code or passing tests. No Marketplace release is included.
